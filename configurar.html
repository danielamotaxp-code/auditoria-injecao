1. Chave do GitHub

O site usa uma chave (token) do GitHub para ler a lista de auditorias e guardar as planilhas no repositório privado. Para criar:

  1. No GitHub: Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token (em português: Configurações › Configurações de desenvolvedor › Tokens de acesso pessoal › Tokens refinados › Gerar novo token).
  2. Em Repository access, escolha Only select repositories e marque auditoria-injecao e auditoria-dados.
  3. Em Permissions › Repository permissions: Contents: Read and write e Actions: Read and write.
  4. Gere e cole aqui. A chave não aparece para ninguém: ela fica guardada trancada pela senha de cada pessoa.

2. Pessoas

Cada pessoa entra com o nome e a própria senha.
